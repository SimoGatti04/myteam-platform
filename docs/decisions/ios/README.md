# Snapshot di ADR iOS pertinenti

Questi file sono copie di riferimento, in sola lettura, dei documenti presenti in `AURINFORMATC/app/docs/decisions/`. Sono stati copiati il 28 ottobre 2026 dal working tree locale di AURINFORMATC (HEAD sorgente `2bb9459c6f5efa7ea9b41c00b1eb658dbbc21e27`); alcuni documenti sorgente erano modificati o non tracciati in quel momento. Gli originali non sono stati spostati né modificati.

Queste copie preservano il contesto delle specifiche di piattaforma; non sostituiscono lo stato, l'architettura o la storia autorevoli dell'app iOS. Prima di un cambiamento iOS o di una decisione d'integrazione, verificare il repository sorgente aggiornato. ADR-0005 non è incluso perché superato secondo l'indice sorgente.
